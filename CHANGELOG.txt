MindQuest Memory Lab — v8.38

3–5 AGE BAND PACING REBALANCE

This build corrects an earlier testing mix-up where timing changes were made while the 15–18 age band was being tested and then carried into the younger experience.

For ages 3–5:
- Reduced the general memorisation/study windows across Memory Lab so children do not have to wait unnecessarily after they have encoded the material.
- Reduced the general response windows while keeping enough time to answer comfortably.
- Direction Memory now uses a compact study window appropriate to its smaller 3–5 sequence.
- Grid Recall now uses a shorter study window and retains its small 2–3 location load.
- Order Builder now uses a shorter study window and retains its compact 2–3 item load.
- Activities using the shared age-profile timer (Visual Recall, Sequence Recall, Pair Memory, Location Memory, Feature Memory, Category Recall, What's Missing, Count & Recall, Change Detective) inherit the corrected 3–5 pacing.
- Older age groups remain unchanged by this 3–5-specific correction.

DESIGN PRINCIPLE
The 3–5 experience should feel playful and achievable: enough time to notice and encode, but not so much that the child is forced to sit through a long countdown after they already know the answer.
