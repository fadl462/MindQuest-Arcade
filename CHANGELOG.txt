MindQuest Memory Lab v8.34

Pacing, age-scaling and cognitive-load correction across Memory Lab:
- Reverse Recall now uses a dedicated age- and level-aware item cap instead of inheriting the full generic Memory Lab item count.
- Switchback Recall now uses compact streams with age-aware item caps; younger eligible players receive fewer items, while older players only gain additional items late in the pathway.
- Reverse Recall timing is now deliberately paced for play and learning, with longer study and response windows that scale with age and sequence length.
- Switchback Recall now has a dedicated memorisation phase with a visible countdown and a dedicated response window.
- Dual-Sequence and Interference Recall now use the same age-aware cognitive-load approach, preventing unnecessarily large advanced-memory displays.
- Added a runtime safety gate ensuring ages 3–5 can never be sent into Tier 4 mechanics (Reverse, Dual-Sequence, Interference or Switchback), even if an old cached schedule is present.
- Ages 3–5 retain the lighter Tier 1–3 pathway defined by the Memory Lab master specification.
- Updated instruction-screen timing calculations to match the actual advanced-activity timers.
- Bumped memory-lab.js cache version to 8.34.

MindQuest Memory Lab v8.32

Interference Recall memorisation/timing fix:
- Replaced the generic short study timer with a dedicated 16–22 second study window based on sequence length.
- Added a visible memorisation countdown so the player can clearly see how much study time remains.

- Added a dedicated response window of at least 30 seconds.
- Updated the Memory Lab instruction screen so Dual-Sequence and Interference Recall show their actual extended study/response timings instead of the generic profile timer.
- Bumped memory-lab.js cache version to 8.32 in index.html.

v8.33 — Reverse Recall timing fix
- Reworked Reverse Recall with a dedicated age-aware memorisation window for all five age categories.
- Added a visible study countdown so the player knows exactly how much memorisation time remains.
- Reverse Recall study time now scales with both age category and sequence length, with a 11–32 second range.
- Reverse Recall response time now scales with age and sequence length, with a 30–50 second range.
- The response phase explicitly tells the player to start with the last object and work backwards.
- Updated the instruction-screen timing calculation so the displayed Reverse Recall timings match the actual activity timers.
